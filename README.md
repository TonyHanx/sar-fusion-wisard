# sar-fusion-wisard

Detección de personas ocultas por vegetación en imágenes de dron con fusión temprana RGB-térmica (YOLO26s),
evaluada por nivel de oclusión sobre el dataset WiSARD (Broyles et al., 2022).

Tesis de pregrado, Ingeniería de Sistemas, Universidad de Lima. Seminario de Investigación I.

- `CLAUDE.md`: contexto, datos verificados y decisiones del proyecto.
- `FASES.md`: pasos del trabajo, uno por fase.

El dataset no se incluye en el repositorio. Se descarga de https://sites.google.com/uw.edu/wisard/
